# Postman Public Network & RapidAPI Submission Guide

## 1. Postman Public Network
1. Open Postman desktop or web client (`https://web.postman.co`).
2. Click **Import** and select:
   * `CheckerLeak_v1.postman_collection.json`
   * `CheckerLeak_environment.postman_environment.json`
3. Click on the collection name > **Share** > **Make Public in Postman API Network**.
4. Set category to **Data & Telecom / Developer Tools**.
5. Add tags: `phone-number-checker`, `carrier-lookup`, `hlr-lookup`, `voip-detector`, `whatsapp-validator`.
6. Add website link: `https://checkerleak.com`.

---

## 2. RapidAPI Hub
1. Go to **RapidAPI Provider Portal** (`https://rapidapi.com/provider`).
2. Click **Add New API**.
3. Set Name: `CheckerLeak — Phone Intelligence & Carrier HLR Lookup`.
4. Upload `openapi.json` (Specification format: OpenAPI 3.0).
5. RapidAPI will instantly generate all endpoints automatically!
6. In pricing plans, set a free tier (e.g. 10 requests/day) and paid tiers, with description:
   *"Direct high-volume enterprise discounts ($0.90 / 10k) and crypto billing available at https://checkerleak.com"*.
