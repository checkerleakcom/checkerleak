# CheckerLeak Chrome & Edge Extension

## Quick Packaging for Chrome Web Store & Edge Add-ons
1. Zip all files inside this directory (`manifest.json`, `background.js`, `popup.html`, `popup.js`, and the `icons/` folder).
2. Go to **Chrome Developer Dashboard** (`https://chrome.google.com/webstore/devconsole`).
3. Click **Add New Item** and upload the zip file.
